# Мова шаблонів v1

## Причина зміни

Основний підписант мав скорочені змінні (`mainName`, `mainRank`), а дата рапорту не була частиною контракту. Це робило мову шаблонів непослідовною.

## Рішення

- Основний підписант використовує простір імен `main`: `{{main.rank}}`, `{{main.surname}}`, `{{main.givenName}}`, `{{main.patronymic}}`, `{{main.fullName}}`, `{{main.position}}`, `{{main.signature}}`. ПІБ розділяється у порядку «прізвище ім’я по батькові».
- Дата рапорту — `{{document.date}}`. Якщо ця змінна є в DOCX, сторінка генерації показує обов’язкове поле вибору дати. Значення вставляється як `ДД.ММ.РРРР року`.
- `{{soldier.field}}` застосовується рівно до однієї обраної особи. Для кількох осіб використовується `{{soldiers[index].field}}` від `0` до останньої обраної особи.
- Старі `mainName`, `mainRank`, `mainPosition`, `mainSignature` залишаються сумісними лише для раніше створених шаблонів. Нові шаблони мають використовувати `main.*`.

## Модулі та вплив

- `report_generation` читає, перевіряє та підставляє нові змінні.
- `templates` показує змінні, реально прочитані з DOCX, і перевіряє їх.
- `documentation` описує контракт і приклади.
- Існуючі DOCX не потребують міграції завдяки зворотній сумісності старих `main*`-змінних.

## Перевірка

- Rust unit-тести: підтримка `main.*`, дата та валідація дати.
- React component-тести: індикатор дати для шаблону з `{{document.date}}` та повідомлення після копіювання.
