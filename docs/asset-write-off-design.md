# Облік списання майна

## Джерело запису

Запис списання автоматично створюється для кожної одиниці майна, пов’язаної з інцидентом `Втрата майна` або `Втрата БпЛА`. Інцидент втрати військового квитка чи посвідчення УБД не є майновим списанням і не створює запису. Повторне відкриття старої бази доповнює чергу зі старих інцидентів без дублів.

## Стани

1. `Очікує списання`.
2. `Документи готуються`.
3. `Передано на списання`.
4. `Списано`.
5. `Скасовано`.

Кожна зміна стану і примітки записується в історію. Завершене списання не повертається у попередній стан.

## Вплив на облік

До стану `Списано` запис майна не змінюється. Після підтвердження списання майно:

- отримує стан `Списаний`;
- знімається з відповідальної особи та екіпажу;
- для БпЛА прибирається як основний БпЛА екіпажу;
- для техніки синхронно оновлюється пов’язаний запис автомобіля;
- залишається в базі та історії руху, а не видаляється.

Зв’язки з інцидентом і майном допускають відсутній запис після вибіркового імпорту: історичні назва, номери, кількість і служба залишаються доступними.
