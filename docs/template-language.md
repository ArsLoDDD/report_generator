# Мова шаблонів рапортів

## Призначення

Шаблон DOCX містить змінні у подвійних фігурних дужках. Під час генерації система замінює їх даними з SQLite та налаштувань програми.

```text
{{soldiers[0].surname}}
```

Змінні чутливі до регістру. Пробіли всередині дужок не допускаються.

## Військовослужбовці

Для одного або кількох обраних військовослужбовців використовується колекція `soldiers`.

| Змінна | Дані |
| --- | --- |
| `{{soldiers[0].rank}}` | Звання |
| `{{soldiers[0].surname}}` | Прізвище |
| `{{soldiers[0].givenName}}` | Ім'я |
| `{{soldiers[0].patronymic}}` | По батькові |
| `{{soldiers[0].fullName}}` | Повне ПІБ |
| `{{soldiers[0].position}}` | Посада з військовою частиною |
| `{{soldiers[0].taxId}}` | ІПН |
| `{{soldiers[0].birthDate}}` | Дата народження у форматі `ДД.ММ.РРРР року` |
| `{{soldiers[0].educationLevel}}` | Формат освіти |
| `{{soldiers[0].educationDetails}}` | Де здобуто освіту |
| `{{soldiers[0].armedForcesServiceStartDate}}` | З якого часу в ЗСУ |
| `{{soldiers[0].positionAssignedDate}}` | Дата призначення на посаду |
| `{{soldiers[0].positionAssignmentOrder}}` | Наказ про призначення |
| `{{soldiers[0].militaryId}}` | Військовий квиток |
| `{{soldiers[0].assignedVehicleName}}` | Закріплений автомобіль |
| `{{soldiers[0].assignedVehicleRegistration}}` | Номер автомобіля |

`[0]` — перший обраний військовослужбовець, `[1]` — другий. Для шаблону на одну особу дозволено використовувати лише `[0]`.

## Службові змінні

| Змінна | Дані |
| --- | --- |
| `{{mainRank}}` | Звання основного підписанта |
| `{{mainName}}` | ПІБ основного підписанта |
| `{{mainPosition}}` | Посада основного підписанта |
| `{{mainSignature}}` | Шлях до зображення підпису |
| `{{commanderName}}` | ПІБ командира |
| `{{chiefName}}` | ПІБ начальника штабу |

## Майбутні затверджені поля

Нове поле додається до словника БД із стабільним ключем у `camelCase`. Воно стає доступним як `{{soldiers[0].newFieldName}}` лише після оновлення Rust-словника та повної перевірки шаблону.

## Перевірка

- Швидка перевірка перед генерацією перевіряє синтаксис і наявність даних для обраних осіб.
- Повна перевірка в «Шаблонах» також повертає попередження й інформацію про невідомі або застарілі змінні.
