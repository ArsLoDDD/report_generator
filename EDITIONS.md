# Редакції Шаблонізатора

Проєкт випускається у двох редакціях з однієї кодової бази.

## Проста версія

Призначена для роботи з особовим складом і документами:

- Генерація рапортів;
- Шаблони;
- Аналізатор рапортів;
- Згенеровані рапорти;
- Конструктор змінних;
- Особовий склад і його Excel-імпорт/експорт;
- Налаштування підписантів.

У меню не відображаються реєстри автомобілів, екіпажів, майна, позицій, інцидентів, штатки та БЧС.

## Просунута версія

Містить усі можливості простої версії та операційні реєстри.

## Збірка

```bash
npm run tauri:build:simple
npm run tauri:build:advanced
```

GitHub Actions створює окремі Windows-інсталятори для обох редакцій. Для цього не потрібні секретні ключі GitHub. Окремий ключ буде потрібний лише для підпису Windows-інсталятора або автоматичного оновлення програми.
