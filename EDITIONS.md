# Редакції Шаблонізатора

Проєкт випускається у трьох редакціях з однієї кодової бази.

## Проста версія

Призначена для роботи з особовим складом і документами:

- Генерація рапортів;
- Шаблони;
- Аналізатор рапортів;
- Згенеровані рапорти;
- Конструктор змінних;
- Особовий склад і його Excel-імпорт/експорт;
- Налаштування підписантів.

У меню не відображаються реєстри автомобілів, екіпажів, майна, позицій, інцидентів, штатки та БЧС.

## Просунута версія

Містить усі можливості простої версії та операційні реєстри.

## Адмінська версія

Окремий застосунок центру керування підрозділами. Він не відкриває локальні
операційні реєстри простої чи просунутої редакції. У ньому адміністратор:

- створює картки підрозділів;
- визначає тип, назву, підпорядкування та штатний скелет;
- випускає основний і резервні коди активації;
- бачить, які коди використані та які інсталяції підключені;
- блокує коди або інсталяції без видалення історії.

Без адреси сервера редакція працює в локальному демонстраційному режимі. Такі
коди позначені як локальні й не можуть активувати бойову програму. Контракт API,
таблиці Supabase та правила безпеки описані в
`docs/admin-edition-supabase.md`.

## Збірка

```bash
npm run tauri:build:simple
npm run tauri:build:advanced
npm run tauri:build:admin
```

GitHub Actions створює окремі Windows-інсталятори для всіх трьох редакцій. Для цього не потрібні секретні ключі GitHub. Окремий ключ буде потрібний лише для підпису Windows-інсталятора або автоматичного оновлення програми.
